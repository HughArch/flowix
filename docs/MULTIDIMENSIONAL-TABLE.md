# 多维表格文件格式与桌面端实现

集合公共格式、统一索引、改名和展示身份见 [集合索引](COLLECTION-INDEX.md)。磁盘文件使用 schema v2：字段在 `payload.dataset.schema`，记录与取数规则在 `payload.dataset.records`、`payload.dataset.filter`，视图在 `payload.views`。前端仍将它适配到表格 surface 使用的运行时模型。

## 文件身份与存储

- 独立表格保存为 `<名称>.index.yaml`；文件夹表格保存为该文件夹根目录下的 `.index.yaml`。
- 新建和写入使用统一集合 schema v2；旧 `.table.yaml`、`.table.yml` 和 schema v1 文件继续读取。
- 集合身份写入 `collection.id`，格式为 `col_<uuidv7>`；文件名和相对路径不构成身份。
- 表定义、视图、字段选项、笔记引用和 revision 都保存在这一个文件中；笔记属性值保存在对应笔记 frontmatter 中。
- 新文件放在当前笔记本的文件树目录；从文件树当前目录创建时使用该目录，否则使用笔记本默认创建目录。
- 该文件不是 Markdown 笔记，不进入笔记索引，也不通过文档编辑器编辑。工作区解析集合 envelope 后展示表格 surface；集合类型由 `collection.type` 决定。
- 云同步暂不包含表格文件。

## ID 规则

所有 ID 都由 Flowix 在创建对象时生成，不由用户输入，也不从名称派生。使用 UUIDv7，转为 32 位小写十六进制（去掉连字符），再加对象前缀：

| 对象 | 格式 |
| --- | --- |
| 表格 | `col_<uuidv7>` |
| 字段 | `fld_<uuidv7>` |
| 选项 | `opt_<uuidv7>` |
| 视图 | `view_<uuidv7>` |
| 记录 | `rec_<uuidv7>` |

ID 创建后不可因改名或排序而变化。磁盘 `dataset.records.include` 保存手动关联记录，`exclude` 保存排除项；`dataset.filter` 保存规则取数条件。前端兼容的运行时投影仍以 `records.data` 和 `records.auto_collect` 表示这些内容。自动收集条件候选来自笔记列表，不包含图片、视频等非笔记文件；匹配结果只在运行时计算。所有属性值只存在于对应笔记 frontmatter，不复制到集合文件。属性字段通过 `property_key` 读取和更新 frontmatter。单选和多选在笔记中写入选项显示名称，选项 ID 仅供表格配置引用。视图配置通过字段 ID 引用字段。

## 字段类型与值

字段定义使用 `id`、`type`、`property_key`，以及可选的显示名 `name`、选项 `options` 和图片多值标记 `multiple`。`type` 是稳定的机器值，显示名只用于界面展示。

| 类型 | YAML 值 | 说明 |
| --- | --- | --- |
| `primary` | 笔记本内相对路径字符串 | 固定为首列，属性键为 `note`；不可改类型。 |
| `Text`、`URL`、`Icon` | 笔记 frontmatter 字符串 | 文本、URL、Flowix 图标资源 ID |
| `Boolean` | 布尔值 | `true` / `false` |
| `Number` | 数字 | 有限数值 |
| `Date` | `YYYY-MM-DD` 字符串 | 日期 |
| `Select` | 笔记 frontmatter 中的选项显示名称 | 单选；表格文件内选项定义仍由 `opt_` ID 标识 |
| `MultiSelect` | 笔记 frontmatter 中的选项显示名称数组 | 多选；表格文件内选项定义仍由 `opt_` ID 标识 |
| `Tag` | 笔记 frontmatter 字符串数组 | 自由标签 |
| `Tags` | 笔记 frontmatter 笔记标签路径数组 | 对齐笔记属性中的“笔记标签”语义 |
| `Color` | 笔记 frontmatter 颜色值数组 | 复用笔记属性颜色值 |
| `Image` | 笔记 frontmatter 附件相对路径；`multiple: true` 时为路径数组 | 文件本身不嵌入 YAML，表格 surface 显示图片预览 |

每个扩展属性字段包含 `property_key`，作为笔记 frontmatter 的属性键；可选的 `name` 是独立显示名，未设置时由属性偏好设置解析。修改显示名不迁移笔记属性键。`options` 项也有 Flowix 生成的 `opt_` ID。视图中的字段引用、重复 ID、字段类型与值不匹配、无效视图引用会被拒绝显示，并提示用户检查文件。笔记条件匹配的 `property_conditions[].field_id` 可以是表格字段 ID，也可以直接是未配置为表格字段的笔记 frontmatter 属性键。

## 模块边界

- `model.ts` 定义表格运行时模型、默认文档、schema v2 适配和结构校验；序列化将运行时 `records.data`、`records.auto_collect` 转成统一 `dataset` 与 `views` 结构。表格记录不携带笔记属性值。
- `parse-table-document.ts` 负责异步解析入口；达到 128 KiB 的 UTF-8 文件交由专用 Web Worker 解析。
- `use-table-session.ts` 管理单表加载、笔记本解析、竞态隔离、CAS 保存与冲突重载。
- `use-table-cell-writer.ts` 管理单元格 frontmatter 写入队列、乐观更新、错误回滚和单元格保存状态。
- `table-field-header.tsx` 承载字段菜单、选项草稿和独立的条件匹配规则编辑入口；字段保存与属性迁移仍由 `table-document-view.tsx` 协调。
- `table-record-row.tsx` 与 `table-secondary-views.tsx` 分别承载记录行交互和看板/日历呈现；`table-document-view.tsx` 负责协调表格界面与操作。

## 当前桌面端行为

- 新建入口提供“笔记 / 多维表格”选择。新建表格时输入表名，Flowix 生成文件名和全部初始 ID，并在创建后打开表格 surface。
- 文件树中新建表格默认以数据表为首个视图；编辑器 slash 命令可直接以数据表、看板、日历或画廊列表为首个视图。看板新建时会明确提示同时新增共享的“状态”单选属性；日历默认使用笔记创建时间。新增记录时从当前笔记本选择已有笔记，每篇笔记在一张表中只能关联一次。
- 文件树“视图”分组只展示明确加入分组的表格；普通入口创建的表格默认隐藏，从“视图”分组创建的表格默认加入。行菜单可添加或隐藏表格。该展示偏好保存在笔记本索引中，以 `collection_id` 为键，不写入表格 YAML，因此重命名和重建文件目录索引时仍保留。复制文件造成 `collection_id` 重复时，列表会标记冲突并暂停分组状态修改；可在副本行菜单为所选文件生成新 `collection_id`，同时递增文档 revision。字段、记录和视图 ID 保持不变，新 ID 使用独立的默认分组状态。
- 字段定义由整张表共享，笔记属性值仍保存在对应笔记 frontmatter。视图按字段 ID 读取同一批记录；数据表视图的 `visible_fields` 独立控制列显隐。导航栏中的“属性”入口在所有视图下均可管理共享字段。
- 编辑器引用先选择表格，再选择具体视图；同类型视图可有多个。也可为已有表格创建所需类型的视图，引用节点保存所选 `viewId`。缺失的视图需要用户显式改选，不会自动切换到第一个视图。
- 新增属性列时，字段名映射为笔记 frontmatter 的 `property_key`；编辑单元格直接写入笔记属性，表格 YAML 不复制属性值。
- `note_path` 保存笔记本内相对路径；表格首列显示笔记标题并可打开笔记文档。
- 运行时自动收集条件可匹配笔记属性、笔记名称、笔记文件夹和 Markdown 类型；属性条件既可以引用已有表格字段，也可以直接填写任意笔记 frontmatter 属性键。属性条件组可设为并集或交集，文件条件按并集匹配。条件结果与显式记录按笔记路径去重，不会写入显式记录。移除条件结果会记录排除路径，避免该笔记再次出现在匹配结果中。导航栏的“条件匹配”入口在所有视图下均可使用。
- 草稿行或无法解析关联笔记的行保留在表格中，属性单元格不可编辑；笔记列表加载失败时显示“无法确认”并可重试。列表成功加载但仍找不到关联笔记时保留原路径，显示“关联失效”，可从主字段更换关联。
- 笔记在笔记本内更名或移动时，Flowix 尝试静默改写多维表记录及自动收集排除路径；改写失败不阻塞笔记操作，表格后续加载时保留原路径并显示失效状态，供用户修复。
- 从表格移除行只删除表格中的笔记引用，不删除笔记文件及其 frontmatter 属性。
- 图片属性通过笔记本相对附件路径保存在笔记 frontmatter；文件本身不嵌入 YAML，表格 surface 显示图片预览。
- 数据表每页展示至多 100 条记录；看板与日历对当前记录建立分组索引；图片读取限制为最多 4 个并发请求，同一路径在单次加载中复用结果。
- 写入走桌面端受 notebook scope 限制的文件 API，采用原子写入与基于原始文件内容的 compare-and-swap；遇到外部修改时重新载入最新版本。
- 字段类型变更先校验已关联记录的值，不兼容时拒绝变更；删除字段只删除表格配置，保留笔记中的 frontmatter 属性值。被看板分组或日历日期引用的字段须先调整相关视图，才能改成不兼容的类型或删除。

## 性能基准

在 Apple M4 / macOS 26.5.1 / Node 24.15.0 上，对 1,000 条记录、20 个字段、200 个图片属性引用的合成数据运行 25 轮基准；静态组件渲染测量 7 轮。记录只包含 `note_path`，属性值单独保存在基准笔记对象中。结果为：

| 操作 | 中位数 | P95 |
| --- | ---: | ---: |
| YAML 解析（同步基线） | 20.97 ms | 27.51 ms |
| YAML 序列化 | 7.12 ms | 9.58 ms |
| 已解析对象结构校验 | 0.19 ms | 0.30 ms |
| 1,000 条记录分组 | 0.04 ms | 0.10 ms |
| 看板 1,000 张卡片静态渲染 | 8.44 ms | 19.35 ms |
| 日历静态渲染 | 3.86 ms | 16.34 ms |

真实数据模型下 YAML 为约 164 KB，较重复存值的压力样本约 1.3 MB 缩小 87%；同步解析中位数由约 118 ms 降至约 21 ms。数据表每页限制 100 行；达到 128 KiB 的表格文件改由 Web Worker 解析。视图数据来自独立的笔记属性映射；静态渲染指标不包含桌面 WebView 的布局绘制、滚动帧时间和真实点击到反馈延迟。
